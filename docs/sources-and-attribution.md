## Dataset

The indoor RGB-D data is the **TUM RGB-D SLAM Dataset and Benchmark**, by J. Sturm, N. Engelhard, F. Endres, W. Burgard and D. Cremers. Reference: *A Benchmark for the Evaluation of RGB-D SLAM Systems*, IROS, 2012.

- [Dataset and licence](https://cvg.cit.tum.de/data/datasets/rgbd-dataset)
- [File formats and depth scaling](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/file_formats)
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The official page states that benchmark data is CC BY 4.0 unless otherwise stated. Published trajectories and map preview are derived from `freiburg1_desk`. Changes include frame association, depth conversion, motion estimation, graph optimisation, point reconstruction and preview subsampling. Raw images and motion-capture files are not redistributed in this snapshot.

## Tools and authorship

- [RTAB-Map ROS](https://github.com/introlab/rtabmap_ros): existing odometry and SLAM implementations.
- [Open3D](https://www.open3d.org/): existing geometry and point-cloud processing.
- [evo](https://github.com/MichaelGrupp/evo): trajectory evaluation.

The learning project used official examples, documentation and AI-assisted coding/debugging. The portfolio does not claim ownership of those underlying algorithms. Third-party libraries retain their licences. No blanket licence is applied to the original portfolio text/code; public visibility alone is not a grant of unrestricted reuse. Dataset-derived content remains subject to the dataset terms.

## Publication choices

This snapshot selects reports, portable scripts/configurations, lightweight evidence and figures. It excludes local usernames/absolute paths, credentials, private correspondence, computer inventories, full raw datasets, the 237 MB database, the full 32 MB map and unrelated documents. Publication dates are current; original September experiment dates are preserved without backdating GitHub commits.
